# Bayesian Study Planner

## Overview

The Bayesian Study Planning system is a project that seeks to help students make better decisions about how to organize their study time.

Students often have to balance several things, including upcoming exams, assignment deadlines, available study time, and stress. This project will use a Bayesian Network to model some of these factors and estimate how they may affect a student's exam performance and stress level.

Based on these estimates, the system will compare different study options using a utility function and recommend an option that balances academic performance with stress management.

## Project Objectives

The main objectives of this project are to:

- Develop a Bayesian Network to represent factors that influence student performance and stress.
- Define Conditional Probability Tables (CPTs) to describe the relationships between the variables.
- Use probabilistic inference to estimate the likelihood of exam success and different stress levels.
- Apply a utility function to compare possible study decisions.
- Recommend study actions based on their expected utility.
- Integrate a calendar API to help students organize their recommended study sessions.
- Test the system using different student scenarios.

## Technologies

The project is expected to use:

- **Python** – Main programming language.
- **Bayesian Network library** – For building the network and performing probabilistic inference.
- **Calendar API** – For managing study schedules.
- **Streamlit** – For developing the user interface.
